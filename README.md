# Jekyll (Cayman) — Variant
1) Upload this **docs/** folder to your repo.
2) Enable GitHub Pages: **Settings → Pages** → Deploy from a branch → `main` • `/docs`.
3) Replace `docs/assets/resume.pdf` with your own resume file.
4) Optional: link `assets/css/custom.css` from `_layouts/default.html` if you want deeper overrides.
